# Student Daily Expense Tracker

## 📖 Project Overview
The Student Daily Expense Tracker is a Python-based console application that helps students record and manage their daily expenses. It allows users to keep track of their spending, organize expenses into categories, and monitor their budget.

## 🎯 Objectives
- Practice Python fundamentals
- Learn file handling
- Improve problem-solving skills
- Build a portfolio project

## 🛠️ Technologies Used
- Python
- JSON (later)
- VS Code

## 🚀 Planned Features
- Add Expense
- View Expenses
- Update Expense
- Delete Expense
- Search Expense
- Budget Tracker
- Category Summary
- Monthly Report
- Data Visualization (Future)
